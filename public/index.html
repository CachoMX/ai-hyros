Step 1 of 3

Storage needs to be set up.

This dashboard keeps your snapshots, settings and encrypted API keys in a free Upstash Redis database attached to the Vercel project. Nothing else is required.

  1. Open the project in Vercel → Storage tab → Create Database.
  2. Pick Upstash → Redis (the free plan is plenty) → Continue.
  3. Connect it to this project for all environments. Vercel adds the KV_REST_API_URL / KV_REST_API_TOKEN variables itself.
  4. Redeploy (Deployments → ⋯ → Redeploy) so the functions pick the variables up, then come back here.
Step 2 of 3

Connect your HYROS account.

Paste the API key from HYROS (Settings → API) and choose the password this dashboard will ask for from now on. The key is checked with HYROS, encrypted, and never shown again; the first snapshot builds right away.

Connect HYROS

Connect your HYROS account.

Paste the API key from HYROS (Settings → API). It is checked against HYROS, encrypted, and never shown again. The first snapshot builds right away — usually under a minute.

Step 3 of 3 · optional

Lock it down.

Two secrets were generated for you and are stored in your database. Moving them into Vercel as environment variables keeps the encryption secret out of the same store as the encrypted keys and signs the daily refresh. Optional — everything works either way.
